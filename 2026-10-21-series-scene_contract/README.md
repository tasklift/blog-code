# 2026-10-21-series-scene_contract

A scene contract schema, a grading prompt and a pass rule for checking AI pictures against the script.

**요약** 원고에서 뽑은 장면 계약 형식, 채점 지시문, 합격 규칙입니다.

## Run

```bash
python main.py
```

The code runs on small sample data that ships in this folder, so it works offline.

## Results

In the post, before the contract only 3 of 16 scenes passed on the first candidates (about 19%).

Those numbers are the author's own measurements described in the post; the sample data here only demonstrates the code.
