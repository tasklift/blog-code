# 2026-10-21-data-title_features

Hit rate (views at least 3x the channel median) by title length bucket.

**요약** 제목 길이 구간별로 터진 영상(채널 중앙값의 3배 이상) 비율을 셉니다.

## Run

```bash
python main.py
```

The code runs on small sample data that ships in this folder, so it works offline.

## Results

In the post, 14.0% of 719 videos were hits; 5.8% at 15 characters or fewer vs 16.5% at 36 or more (correlation only).

Those numbers are the author's own measurements described in the post; the sample data here only demonstrates the code.
