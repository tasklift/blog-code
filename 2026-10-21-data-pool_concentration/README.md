# 2026-10-21-data-pool_concentration

Median vs mean and top-10% share of a view-count list, to judge a channel against its own median.

**요약** 조회수 목록의 중앙값·평균·상위 10% 몫을 계산해 내 채널을 중앙값과 견줍니다.

## Run

```bash
python main.py
```

The code runs on small sample data that ships in this folder, so it works offline.

## Results

In the post, the top 10% of 1,381 videos took 64.3% of all views (median 28,296, mean 165,972).

Those numbers are the author's own measurements described in the post; the sample data here only demonstrates the code.
