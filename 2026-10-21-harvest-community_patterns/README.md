# 2026-10-21-harvest-community_patterns

Top-10% view threshold of a board and how over-represented each post format is among top posts.

**요약** 게시판의 상위 10% 조회수 문턱과, 상위 글에서 글 형식이 얼마나 많이 보이는지(배수)를 잽니다.

## Run

```bash
python main.py
```

The code runs on small sample data that ships in this folder, so it works offline.

## Results

In the post, 2,944 classified posts from 10 boards; one board's top-10% threshold was about 7.9x its median.

Those numbers are the author's own measurements described in the post; the sample data here only demonstrates the code.
